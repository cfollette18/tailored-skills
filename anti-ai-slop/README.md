# Anti-AI-slop skills

All anti-slop skill directories are collected here. Each folder retains its own `SKILL.md` and any supporting resources. Import this category with `hermes profile import /path/to/tailored-skills/anti-ai-slop`.

## General quality

- [anti-slop-principles](anti-slop-principles/SKILL.md) — choose the appropriate quality review.
- [design-anti-slop](design-anti-slop/SKILL.md) — detect and repair generic interface patterns.
- [writing-anti-slop](writing-anti-slop/SKILL.md) — clear, concrete writing.
- [code-anti-slop](code-anti-slop/SKILL.md) — remove unnecessary code and abstractions.
- [agent-artifact-anti-slop](agent-artifact-anti-slop/SKILL.md) — improve skills, plans, and handoffs.

## Color direction and consistency

- [restrained-color-design](restrained-color-design/SKILL.md) — brand-agnostic palette roles and purposeful emphasis.
- [color-consistency-review](color-consistency-review/SKILL.md) — audit and repair theme drift across product surfaces and states.

Frontend implementation and validation are in [semantic-color-theming](../01-ui-design/semantic-color-theming/SKILL.md) and [theme-accessibility-validation](../01-ui-design/theme-accessibility-validation/SKILL.md).

## Animation and motion quality

- [motion-anti-slop](motion-anti-slop/SKILL.md) — choose purposeful, brand-appropriate motion and preserve specifically requested icon character.
- [motion-quality-review](motion-quality-review/SKILL.md) — review live choreography, repeated use, interruptions, and reference fidelity.

Frontend implementation lives in [frontend-motion-system](../01-ui-design/frontend-motion-system/SKILL.md), [animated-interface-icons](../01-ui-design/animated-interface-icons/SKILL.md), and [navigation-and-view-transitions](../01-ui-design/navigation-and-view-transitions/SKILL.md). Use [motion-accessibility-performance](../01-ui-design/motion-accessibility-performance/SKILL.md) for verification and [motion-reference-research](../01-ui-design/motion-reference-research/SKILL.md) for footage analysis. The [Muse study](../01-ui-design/animated-interface-icons/references/muse-sidebar-study.md) preserves the six observed sidebar gestures with cropped, timestamped evidence.
