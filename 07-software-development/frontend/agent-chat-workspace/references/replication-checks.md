# Replication checks

Use fictional event fixtures and the product's existing browser tools. Check behavior rather than exact wording. A visual change does not require a paid model run.

| Exercise | Required observation |
|---|---|
| First visit | Clear task, usable composer, starters seed rather than silently execute |
| Send / Enter / multiline / IME | One intended submission; Shift+Enter inserts a newline; composition does not submit |
| Tool starts | One card appears at the correct place, with a purpose-based progress sentence |
| Wait | Elapsed time advances; no fabricated milestones or percentage; timer does not re-render the whole transcript |
| Tool click / Enter / Space | Details expand directly underneath; trigger retains focus; no competing trace sidebar |
| Tool finishes | Same card settles; elapsed time freezes; snippet reflects the returned outcome |
| Failure / interruption | Readable failure/interruption label; no green success or raw provider exception; retry does not duplicate writes |
| Two overlapping tools | Independent identity, status, and expansion; completed counts come from terminal events |
| Follow-up after interruption | Previous unfinished card stays interrupted; new turn has its own timer and calls |
| Reconnect / reload | No duplicate tool cards or final answers; replay shows saved state; draft/recovery policy is explicit |
| Browse earlier messages | New activity and disclosure expansion do not repeatedly drag the reader to the bottom |
| Small screen / long data | Controls and focus remain reachable; tables/code scroll internally; no page-width overflow |
| Reduced motion | All states remain available immediately; progress is understandable without animation |
| External links / tool payloads | Model content stays data; no raw credential/exception/hidden-reasoning dump |
| Route switch / unmount | Draft preserved as intended; stale events ignored; listeners, timers, animations cleaned up |
| Stop | UI confirms the observed stopped state; already completed side effects are not described as undone |

Capture empty, running, expanded, completed, failed, and mobile states after their entrance motion settles. Automated contrast/token checks complement visual and keyboard inspection. Document incomplete states honestly; the reference demo is not evidence that live authentication, persistence, streaming, or side effects work in a target product.
